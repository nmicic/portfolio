# Nenad Micic — Portfolio

A catalog of 22 public repositories across integer computing, secure systems,
computational search, visual mathematics, and writing tools.

- **[Browse the portfolio](https://nmicic.github.io/portfolio/)**
- **[Compact project table](https://nmicic.github.io/portfolio/catalog/)**
- [GitHub profile](https://github.com/nmicic)

Each project brief explains what was built, the recorded results, and their
limits, with links to the exact source revision reviewed. The current snapshot
was reviewed on October 15, 2026.

To publish, enable GitHub Pages under **Settings → Pages → Deploy from a branch**,
select **main** and **/ (root)**, then save. The links above become available once
Pages is enabled for `nmicic/portfolio` and its first deployment completes.
